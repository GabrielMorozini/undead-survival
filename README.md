# 🧟 Undead Survival

![Badge Concluído](https://img.shields.io/badge/Status-Developing-yellow)
![Pixel Art](https://img.shields.io/badge/Art-2D%20Pixel%20Art-blueviolet)

**Undead Survival** é um jogo de tiro *top-down* (visão aérea) em 2D com estilo clássico em pixel art. O desafio é direto e brutal: você está em uma arena fechada e o seu único objetivo é eliminar todos os zumbis para garantir a sua vitória. 

---

## 🎮 Sobre o Jogo

O desenvolvimento foi concluído! Não há distrações, gerenciamento de inventário ou coleta de recursos. É apenas você, sua arma e uma horda de mortos-vivos. 

### ✨ Funcionalidades Principais
*   **Objetivo Claro:** Derrote exatamente **100 zumbis** para vencer o jogo.
*   **Estética Pixel Art Retro:** Visuais nostálgicos e ambientação sombria de sobrevivência.
*   **Combate Direto:** Sem necessidade de recarregar a arma. Mire, atire e mova-se para não ser encurralado.
*   **Menu de Pausa:** Controle o ritmo do jogo a qualquer momento.

---

## 🕹️ Controles

O jogo oferece suporte tanto para as teclas clássicas de computador quanto para as setas direcionais.

| Comando | Ação |
| :---: | --- |
| **W, A, S, D** ou **Setas (⬅️⬆️➡️⬇️)** | Movimentar o personagem |
| **Mouse** | Mirar (Direcionar a arma) |
| **Ctrl** | Atirar (Munição Infinita) |
| **Esc** | Pausar / Despausar o jogo |
